# せどり一括検索（sedori-multi-search）

店舗せどりの現場（iPhone）で、商品名・メーカーを1回入力して各フリマ・オークションサイトの相場を調べ、
利益計算と仕入れ記録までできるWebツール。`index.html` 1ファイルだけで動く（サーバー・ライブラリ不要）。

- 公開URL：https://ymori3papa-alt.github.io/sedori-multi-search/
- リポジトリ：https://github.com/ymori3papa-alt/sedori-multi-search

## 依頼内容と対応（2026-11-09〜11-24）

| # | 依頼 | 対応 |
|---|------|------|
| 1 | 商品名・メーカーを1回入力して複数サイトを検索したい（メルカリ・ヤフオク・Yahoo!フリマ・ラクマ・オークファン） | 5サイトの検索ボタン。「売り切れで検索」で売り切れ・落札済み相場も確認可 |
| 2 | 音声入力したい | 🎤ボタン（Safariの音声認識）。使えない画面ではiPhoneキーボードのマイクで代用 |
| 3 | メーカーを簡単に入力したい | カテゴリ別のブランドボタン（バッグ・レディース・スポーツ・靴・時計・家電ホビー・キーワード）。タップ＝追加、長押し＝置き換え、「編集」で追加・削除 |
| 4 | iPhoneで使いたい | GitHub Pagesで公開。Safariの「ホーム画面に追加」でアプリのように起動 |
| 5 | 文字入力のキーボードを用意（日本語・英語） | 画面キーボード：「あいう」50音（カナ⇄ひらがな、゛゜小）、「ABC 123」英数・記号、「iPhone」標準キーボード（漢字変換用）。設定でカーナビ式（あが右）も可 |
| 6 | 調べたいサイトを選んで画面遷移したい | サイトボタンをタップ → そのサイトの検索結果へ移動。戻ると入力は残り、開いたサイトは枠表示 |
| 7 | 検索欄の枠を超えると文字が見えない | 検索欄を折り返し表示にし、最大5行まで自動で伸びるように修正 |
| 8 | 簡単な利益計算（販売価格 − 手数料 − 送料 ＝ 利益）、手数料10%・送料1,000円が初期値、変更可 | 利益計算欄を追加。手数料・送料は変更可能で値を記憶、「初期値に」ボタンあり |
| 9 | 仕入れ値の欄を追加 | 利益 ＝ 販売価格 − 手数料 − 送料 − 仕入れ値。仕入れ値があるときは利益率も表示 |
| 10 | 5%・10%を選択でも入力でもできるように（手数料率） | 手数料に「5%」「10%」ボタン＋直接入力（8.8%等も可） |
| 11 | 仕入れボタンと仕入れ一覧、合計を表示 | 「＋ 仕入れる」で一覧に追加。合計（件数・仕入れ合計・販売予定合計・利益合計）を表示。🗑で1件削除、「全削除」で全件削除 |
| 12 | 一覧の金額を修正したい | ✏️で修正可能に |
| 13 | 修正は上の検索欄・金額欄に値を戻して行う方式に | ✏️ → 検索欄と利益計算欄に値が入り「✔ 修正を保存」で更新。「修正をやめる」で取り消し。終わると修正前の入力に戻る |
| 14 | 一覧の金額の文字が小さい | 仕入・販売金額、利益、合計欄の文字を拡大 |
| 15 | 一覧のクリアボタン | 既存の「全削除」で良いとのことで追加分は取り消し |
| 16 | 一覧に番号を付ける | 仕入れた順に番号（1, 2, 3…）を表示。削除すると詰め直し |

## 画面構成（上から）

1. 検索欄（🎤音声入力・✕クリア）
2. 検索サイト（5サイト＋「売り切れで検索」）
3. メーカー・ブランド簡単入力
4. 検索履歴（直近30件）
5. 利益計算（販売価格・手数料・送料・仕入れ値 → 利益・利益率、「＋ 仕入れる」）
6. 仕入れ一覧（合計・番号・✏️修正・🗑削除・全削除）
7. 設定（使うサイト、サイトの開き方、50音の並び）
8. 画面キーボード（画面下に固定）

## データの保存について

- 設定・履歴・仕入れ一覧は、そのiPhoneのブラウザ内（localStorage）にのみ保存される
- Safariの履歴・Webサイトデータを消去すると消える
- iPhoneでは「ホーム画面から開く」と「Safariで開く」で保存場所が別

## 更新方法

`index.html` を修正して `git push` → 1〜2分でGitHub Pagesに反映。

## 注意

- オークファンは検索語をEUC-JPの16進数でURLに埋め込む仕様（`q-~a5eda5f3...`）。変換できない文字（絵文字等）は除外される
- Yahoo!フリマは売り切れ絞り込みをURLで指定できないため、サイト上の「販売状況」で絞り込む

## 検索URL（2026-11-09 動作確認）

| サイト | 販売中 | 売り切れ |
|--------|--------|---------|
| メルカリ | `jp.mercari.com/search?keyword=…` | `&status=sold_out` |
| ヤフオク | `auctions.yahoo.co.jp/search/search?p=…` | `closedsearch/closedsearch?p=…` |
| Yahoo!フリマ | `paypayfleamarket.yahoo.co.jp/search/…` | （URL指定不可） |
| ラクマ | `fril.jp/s?query=…` | `&transaction=soldout` |
| オークファン | `aucfan.com/search1/q-~<EUC-JP hex>/` | 同左（過去相場） |
